# Holder

A card server.

## Development

It should work on Linux, Mac, Windows, etc.

I use Ubuntu, here is how I get a development setup on Ubuntu:

sudo apt install \
  build-essential cmake ninja-build pkg-config \
  libboost-system-dev \
  libsqlite3-dev \
  libgit2-dev \
  libmd4c-dev \
  xdg-utils-cxx-dev \
  nlohmann-json3-dev \
  libspdlog-dev \
  catch2
